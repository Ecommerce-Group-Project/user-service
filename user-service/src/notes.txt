SPRING ROUE to default authentication enrypoint when JWT is invalid

JWT expires/invalid
    ↓
JwtAuthenticationFilter doesn't set authentication
    ↓
Spring Security sees: unauthenticated request
    ↓
Calls default AuthenticationEntryPoint
    ↓
oauth2Login() redirects to Google signin ❌











### 401 Unauthorized situations

1. **No JWT/token** when accessing a **protected endpoint**.
2. **Expired JWT**.
3. **Invalid JWT** — bad signature, malformed token, etc.


### NOT 401

* Valid JWT but insufficient role/authority → **403 Forbidden**.
